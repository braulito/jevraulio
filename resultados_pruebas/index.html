Cómo leer estos informes

Cada enlace corresponde a una prueba ejecutada. Las pruebas aisladas usan datos ficticios y servicios simulados; las de integración consultan los servicios reales ya encendidos y pueden consumir tokens. Un rechazo esperado (403, 422 o 502) puede ser una prueba aprobada si demuestra el bloqueo previsto.

No se modificaron registros MCP ni umbrales de la base real. No se leyeron archivos .env. No se implementó ni evaluó autenticación administrativa: está fuera de este alcance. Estas pruebas no demuestran seguridad absoluta ni resistencia universal a prompt injection.
